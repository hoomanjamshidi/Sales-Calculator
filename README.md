# Sales Calculator — گزارش فروش محصولات ووکامرس

افزونهٔ **فارسی و راست‌به‌چپ** وردپرس برای گزارش دقیق فروش محصولات ساده و **متغیر** در ووکامرس، با تقویم شمسی و میلادی و خروجی **اکسل** و **PDF** (با فونت وزیر).

![نمای کلی گزارش](docs/screenshots/report.png)

## امکانات

- **گزارش به تفکیک محصول و متغیر:** تعداد فروش، مرجوعی، تعداد خالص و مبلغ خالص هر محصول؛ با باز کردن هر محصول، متغیرهایش (رنگ، سایز و …) دیده می‌شود.
- **تقویم شمسی و میلادی:** انتخاب بازه با تقویم دلخواه و پریست‌های آماده (امروز، دیروز، ۷ و ۳۰ و ۹۰ روز اخیر، ماه و سال جاری، بازهٔ دلخواه). ذخیره و API همیشه میلادی است و تقویم فقط برای نمایش است.
- **فیلتر محصول و دسته‌بندی:** انتخاب یک یا چند محصول یا دسته؛ انتخاب دستهٔ والد زیردسته‌ها را هم شامل می‌شود.
- **خروجی اکسل و PDF:** از کل نتیجهٔ گزارش ساخته می‌شود، نه فقط صفحهٔ جاری جدول. PDF با فونت تعبیه‌شدهٔ وزیر و چیدمان راست‌به‌چپ، کارت‌های خلاصه و ردیف جمع کل.
- **محصول حذف‌شده می‌ماند:** فروش محصولی که بعداً حذف شده در جمع‌ها حساب می‌شود و با برچسب «حذف‌شده» نشان داده می‌شود.
- **محاسبهٔ تومانی:** مبالغ ریال، هزار ریال و هزار تومان به تومان تبدیل می‌شوند.
- **سریع روی فروشگاه‌های بزرگ:** گزارش از نمایهٔ مخصوص افزونه ساخته می‌شود، نه مستقیم از سفارش‌ها؛ ساخت گزارش و خروجی در پس‌زمینه (Action Scheduler) انجام می‌شود.
- **سازگار با HPOS** و PHP ‏۸٫۰ تا ۸٫۵.
- **ریسپانسیو:** رابط روی موبایل هم کار می‌کند.
- **نسخهٔ برند:** از همین کد می‌توان نسخهٔ اختصاصی مشتری با لوگو و رنگ دلخواه ساخت ([راهنما](brands/README.md)).

## پیش‌نیازها

- وردپرس ۶٫۶ یا جدیدتر و **ووکامرس** فعال (افزونه به Action Scheduler همراه ووکامرس نیاز دارد)
- PHP ‏۸٫۰ تا ۸٫۵
- افزونه‌های PHP: `bcmath`، `mbstring`، `intl`، `zip` و `gd`؛ اگر `bcmath`، `intl`، `mbstring` یا `zip` نباشد افزونه اجرا نمی‌شود و پیام خطا در پیشخوان نشان داده می‌شود
- پوشهٔ موقت PHP باید قابل نوشتن باشد

## نصب

۱. بستهٔ `sales-calculator-<نسخه>.zip` را از بخش [Releases](https://github.com/hoomanjamshidi/Sales-Calculator/releases) بگیرید، یا آن را [خودتان بسازید](#ساخت-بستهٔ-نصب).

۲. در پیشخوان وردپرس به «افزونه‌ها ← افزودن ← بارگذاری افزونه» بروید، ZIP را نصب و فعال کنید.

۳. صفحهٔ «ووکامرس ← گزارش فروش محصولات» را باز کنید. فقط کاربرانی که مجوز `view_woocommerce_reports` دارند به آن دسترسی دارند.

۴. در نصب اول، سفارش‌ها در پس‌زمینه نمایه‌سازی می‌شوند و تا پایان آن گزارش ساخته نمی‌شود. اگر منطقهٔ زمانی فروشگاه تغییر کند، نمایه خودکار دوباره ساخته می‌شود؛ اگر آماده‌سازی متوقف شد از دکمهٔ «بازسازی نمایه» استفاده کنید.

ZIP نصب به Node یا Composer روی هاست نیاز ندارد و فونت Vazir داخل آن است.

## نحوهٔ استفاده

۱. بازهٔ شروع و پایان را وارد کنید یا یک پریست انتخاب کنید. پیش‌فرض «۳۰ روز اخیر» است؛ دو سر بازه همراه‌اند و روزها با منطقهٔ زمانی تنظیم‌شدهٔ وردپرس تفسیر می‌شوند. تغییر نوع تقویم روز انتخاب‌شده را عوض نمی‌کند.

۲. در صورت نیاز محصول، دسته‌بندی و واحد پول را انتخاب کنید. هر ارز گزارش مستقل دارد و مبلغ ارزهای مختلف با هم جمع نمی‌شود.

۳. روی «نمایش گزارش» بزنید. جدول جست‌وجو، مرتب‌سازی و صفحه‌بندی سمت سرور دارد.

۴. با «خروجی اکسل» یا «دریافت PDF» فایل را بگیرید. خروجی از کل گزارش ساخته می‌شود، مستقل از صفحه یا بازبودن زیرردیف‌ها. PDF با بیش از ۲۰۰۰ ردیف جزئیات به بخش‌های شماره‌دار در یک ZIP تبدیل می‌شود.

## چه چیزی حساب می‌شود؟

- **مبنای زمان، تاریخ پرداخت سفارش است.**
- **وضعیت‌ها:** سفارش‌هایی که ووکامرس «پرداخت‌شده» می‌داند (مثلاً در حال انجام و تکمیل‌شده، و وضعیت‌های سفارشی افزوده‌شده با فیلتر `woocommerce_order_is_paid_statuses`) به‌علاوهٔ سفارش‌های پرداخت‌شده‌ای که بعداً مسترد شده‌اند. فیلتر `sales_calculator_counted_statuses` فهرست نهایی را تغییر می‌دهد.
- **مبلغ:** جمع خالص اقلام پس از تخفیف و کسر مرجوعی؛ مالیات، حمل‌ونقل و هزینه‌ها داخل آن نیستند.
- **تعداد خالص:** تعداد فروش منهای تعداد مرجوعی. مرجوعیِ مبلغی (بدون تعداد) فقط مبلغ را اصلاح می‌کند و مرجوعی بدون انتساب به قلم محصول جدا نمایش داده می‌شود.
- **نام محصول و متغیر** از دادهٔ تاریخی قلم سفارش نگهداری می‌شود، حتی اگر محصول بعداً حذف شده باشد.
- فیلتر `sales_calculator_toman` تبدیل خودکار به تومان را خاموش می‌کند.

## نگهداری و فروشگاه‌های بزرگ

ووکامرس برای آماده‌سازی، همگام‌سازی و خروجی از Action Scheduler استفاده می‌کند. برای فروشگاه‌های بزرگ، cron واقعی سرور را فعال و WP-Cron وابسته به بازدید را غیرفعال کنید. نمونهٔ اجرای هر دقیقه، با جایگزینی مسیر واقعی وردپرس:

```cron
* * * * * /usr/bin/php /path/to/wordpress/wp-cron.php >/dev/null 2>&1
```

- «بازسازی نمایه» نمایهٔ مشتق‌شدهٔ افزونه را دوباره از سفارش‌های ووکامرس می‌سازد و سفارش‌های اصلی را تغییر نمی‌دهد.
- خروجی‌های خصوصی پس از ۲۴ ساعت پاک می‌شوند. مسیر موقت را از وب عمومی دور نگه دارید.
- غیرفعال‌سازی کارهای صف افزونه را لغو می‌کند؛ حذف افزونه، جدول‌ها، تنظیمات و فایل‌های موقت خودش را پاک می‌کند.
- PDF همیشه با فونت وزیر ساخته می‌شود؛ در اکسل نام قلم روی Vazir تنظیم شده و نمایش آن به نصب فونت روی رایانهٔ بازکننده وابسته است.

## توسعه

### ساختار

| مسیر | توضیح |
| --- | --- |
| `sales-calculator.php` | نقطهٔ ورود و بررسی پیش‌نیازها |
| `src/Domain` | تبدیل سفارش به اقلام، اعتبارسنجی فیلتر، تبدیل تومانی |
| `src/Application` | همگام‌سازی نمایه، نسخهٔ ثابت گزارش، صف |
| `src/Infrastructure` | پایگاه داده، جدول‌ها، مخزن نمایه، کاتالوگ |
| `src/Export` | نویسندهٔ اکسل (بدون کتابخانهٔ صفحه‌گسترده)، PDF، قالب تاریخ و عدد فارسی |
| `src/Http` | REST API ‏(`sales-calculator/v1`) و دانلود |
| `ui/src` | رابط React + TypeScript + Tailwind که با Vite ساخته می‌شود |
| `brands/<slug>` | بستهٔ برند اختصاصی مشتری ([راهنما](brands/README.md)) |
| `tests` | آزمون‌های PHPUnit |

رابط با کامپوننت‌های [طرحک](https://tarhak.ir) ساخته شده (`npx @tarhak/cli@latest add <slug>`). شناسه‌های کد انگلیسی و توضیحات به فارسی است و سبک کد WordPress Coding Standards است.

### راه‌اندازی

```bash
composer install
npm ci
```

### بررسی کیفیت

```bash
vendor/bin/phpunit
vendor/bin/phpcs --standard=phpcs.xml        # شامل PHPCompatibility برای PHP ۸٫۰ به بالا
vendor/bin/phpstan analyse --memory-limit=2G
npm run lint && npx tsc --noEmit && npm test
```

### ساخت بستهٔ نصب

```bash
scripts/build_release.sh                # output/sales-calculator-<version>.zip
BRAND=<slug> scripts/build_release.sh   # نسخهٔ برند: output/sales-calculator-<slug>-<version>.zip
```

اسکریپت رابط را می‌سازد، وابستگی‌های PHP را با php-scoper با پیشوند خصوصی ایزوله می‌کند و ZIP نهایی را می‌سازد. `composer.json` پلتفرم را روی PHP ‏۸٫۰ قفل می‌کند تا وابستگی ناسازگار با ۸٫۰ وارد بسته نشود. php-scoper جدا در `tools/php-scoper` نصب می‌شود.

### قواعد مهم

- از ویژگی‌های PHP بعد از ۸٫۰ (`readonly`، `enum`، `never`، …) استفاده نکنید.
- برای تاریخ میلادی هرگز `wp_date()` یا `date_i18n()` نگذارید؛ افزونه‌های شمسی‌ساز خروجی آن‌ها را شمسی می‌کنند. «امروز» از `ReportFilter::today()` می‌آید.
- قرارداد API همیشه تاریخ میلادی `Y-m-d` است.
- پس از تغییر ساختار جدول یا قالب نمایه، `Schema::VERSION` را بالا ببرید؛ ارتقا خودکار نمایه را بازسازی می‌کند.
- پوشهٔ `lib/` خروجی ساخت است و دستی ویرایش نمی‌شود.

جزئیات بیشتر در [CLAUDE.md](CLAUDE.md) و تاریخچهٔ نسخه‌ها در [CHANGELOG.md](CHANGELOG.md) است.
